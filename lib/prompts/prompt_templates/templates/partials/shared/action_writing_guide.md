首帧画面已定格主体、场景与风格，这段文字驱动它动起来：只描述该时长内发生的运动与变化，不复述画面中的静态内容；镜头运动专由 camera_motion 字段承载，action 只写主体与环境的运动。按主体动作（肢体 / 手势 / 表情过渡）、物件互动（摩挲信纸、推门带起的气流等）、环境动态（衣摆、尘埃、雨势、光影移动）分层写成连贯叙述句；动词应描述物理可观察动作（伸手 / 转身 / 摩挲 / 投向 / 收紧），避免内心动词。动作按**正常物理速度**估时：写下每个动作的自然耗时，加总应 ≈ 分镜时长（±20%）——每 2-3 秒安排一个可感知的运动节拍，5 秒级分镜通常完成一个连贯动作 + 一个细节互动，8-9 秒级承载 3-4 个节拍的完整动作链（如「起身—走到窗前—驻足—回望」）加贯穿的环境动态。不要用「缓缓 / 微微 / 渐渐」给短动作注水：一个两秒能完成的动作就配短档分镜，靠副词把 2 秒的动作拉成 9 秒，成片就是慢放；动作可以克制连贯，但节奏必须正常。
   动作按时间顺序展开成一条主线，写下的每个动作都要能在该时长内完成——视频模型沿时间线逐帧消费描述，先后的动作按先后写，不并行跳跃。多主体同框时每人一条独立的动作线，交代完一人再写下一人，不要把多人的动作揉进同一句。
   只写具体可观察的画面细节（手部位置、衣摆方向、尘土轨迹、光源角度变化），不写「电影感」「史诗感」「唯美」「高质量」这类抽象形容词——模型不认识它们，画面信息只来自具体描写，抽象词只会挤占提示词的有效长度。
   正例：「林清缓缓抬起头，眼角微微收紧，手指无意识地摩挲信纸边缘；窗外雨势渐大，桌面投下的雨痕影子在缓慢移动。」——主体动作、物件互动、环境动态各有一笔。
   反例：「林清像蝴蝶般飞舞，思绪在过去与现在之间快速切换。」——「思绪切换」不是可拍摄的运动；「像蝴蝶般」是修辞，不是动作描述。
   避开任务类型触发词：不要用「增加 / 删除 / 去掉 / 修改 / 替换 / 改成 / 延长 / 续写」这类祈使动词。部分模型按 prompt 措辞判定任务类型，带这些词会把参考生视频误判成视频编辑或视频延长。直接描述目标画面本身即可：不写「把外套改成红色」，写「她穿着红色外套」。
   发声与台词一致：action 里写了「说 / 喊 / 念 / 应答」等发声动作时，必须有对应的 Dialogue 条目承载台词；没有台词可写时，把发声意图改成无声动作（嘴唇翕动未出声、欲言又止、以点头示意）——只写「说话」而不给台词，模型会自行发明嘴型与语音，口型与字幕对不上。
   时间轴铺满时长：描述必须覆盖该分镜的全部时长，不能只写两秒的动作量就去填充八秒的视频。多节拍动作按时间轴顺序写并标注起止秒数（分镜时长是确定的，如 9 秒分镜写「0-4 秒老黄蹒跚前行，身影在画面中逐渐变大；4-7 秒他抬头望向城门，脚步放缓；7-9 秒驻足，衣摆随风摆动」）；持续性的环境动态（风雨、尘土、光影）写明贯穿全程，不佯装成某个时间点的独立事件。
